# 引證有據

法律引用核對流程展示原型。以固定案例完整呈現引用來源、文字差異、取得情況，以及這次沒有檢查的事項。

**固定案例用於完整展示不同查核狀態；本頁不是即時查詢，也不是法律建議。**

## 體驗 Demo

[開啟互動原型](https://tsz7250.github.io/citation-check-tw/)

1. 查看預設、不可修改的 AI 法律回覆。
2. 確認五筆引用及其來源。
3. 查看來源、文字差異、取得情況與限制。

## 展示結果

- 與來源原文相同
- 這次查詢沒有找到來源
- 與來源原文不同
- 在已取得的完整內容中找不到這段話
- 這是摘要，不能逐字比對

## 範圍與限制

本頁不會即時呼叫 AI、MCP 或文字比對引擎，也不接收或上傳其他文字。「沒有找到來源」與「在完整內容中找不到引用」是明確標示的模擬案例。結果不判斷法律是否適用、摘要是否正確，或整份回答是否正確。
